# Estande Laser

Treino de tiro a seco com laser. O app usa a câmera do celular para encontrar o ponto vermelho no alvo, pontua cada tiro pelos anéis ISSF e mede o tempo entre o apito e cada disparo (reação e splits).

**Usar:** https://perissatto.github.io/estande-laser/

Modos: Simulação (toque no alvo), Câmera ao vivo e Vídeo gravado (o apito é detectado no áudio).
